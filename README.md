# FerroCAD docs — published site

This repository publishes the FerroCAD user guide (tutorials, how-to guides,
reference, explanation and mod-writing notes) at:

**https://ferrocad.github.io/docs/**

It holds **no documentation and no generator** of its own. The sources, the
builders and the freshness checks live in
[`ferrocad/ferrocad`](https://github.com/ferrocad/ferrocad):

| Path | Role |
| --- | --- |
| `docs/user/` | tutorial, how-to and explanation pages, generated by `tools/userdocs.py` from runnable workflows |
| `docs/python-api/` | signature reference, generated by `tools/api_docs.py` from the live modules |
| `docs/mods/` | the authored contract for mod writers |
| `tools/build_book.py` | assembles those pages into one mdBook and validates every page and link |

`.github/workflows/pages.yml` checks out a **shallow, sparse copy** of
`ferrocad/ferrocad` (`docs/` and `tools/` only), runs
`python3 tools/build_book.py --build`, and deploys the rendered book with GitHub
Pages. Nothing is copied back here, so there is no second copy of the docs to
fall out of date.

## When it refreshes

- **Nightly** at 04:17 UTC, to pick up changes on `ferrocad/ferrocad@main`.
- **On a push to this repository** (for example, a workflow change).
- **Manually:** *Actions → Pages → Run workflow*, or
  `gh workflow run pages.yml -R ferrocad/docs`.
- A `repository_dispatch` of type `ferrocad-main` is accepted, so a token-based
  hook from the source repository can trigger it later without editing the
  workflow.

The pages themselves are checked in `ferrocad/ferrocad`'s `headless` CI job
(`userdocs.py --check`, `api_docs.py --check`, `build_book.py --check`) on every
push. This repository does not duplicate those checks: it only renders what is
committed.

## One-time setup

Settings → Pages → Build and deployment → Source: **GitHub Actions**.

## Preview locally

```sh
git clone --depth 1 https://github.com/ferrocad/ferrocad
cd ferrocad
python3 tools/build_book.py --build   # needs `mdbook` on PATH
# open target/user-book/book/index.html
```
